# Pixel aquarium assets

The current `sprites-fine.png` is a transparent 1254×1504 sheet. Its original 1254×1254 region was generated with the built-in imagegen tool on 2026-10-17, using the user-supplied Kitee / Pixel Aquarium asset board as the style reference. A second imagegen pass cleaned the silhouettes and surrounding transparency. Two matching role icons (chart and palette) were generated separately and appended below the original region, which is preserved unchanged. Their raw sources are `design-assets/hero/chart-source.png` and `palette-source.png`. The full prompt set is in `design-assets/hero/prompts.md`.

`atlas-fine.json` records exact source rectangles plus logical display dimensions and anchors. `scripts/package-hero-fine.mjs` packages the sheet into fourteen 160×160 transparent introduction icons; it does not repaint artwork. `asset-board.html` displays the actual runtime sprites, not a mockup. Sprite source resolution and a 3× Canvas backing store preserve substantially more detail than the first pass. Fine fish silhouettes are about 20–23 logical pixels wide. Plants sway gently around their roots; fish tails bend by less than half a logical pixel while keeping the head and body fixed. Light and dark themes share the same artwork and differ in scene surfaces.

The original code-authored 16×12 fish atlas (`sprites.png`, `sprites-dark.png`, `atlas.json`) is archived locally under the ignored `artifacts/hero-assets/legacy-generated/` directory and is not published. `scripts/build-hero-assets.py` now writes to `artifacts/hero-assets/legacy-generated` so that reproducing it cannot overwrite current assets. Cloud/island motifs were generated in the same style and packaged from `design-assets/hero/motifs-fine.png`. Static posters are captured from the current renderer by `scripts/capture-fine-posters.mjs`.

React, Vue, Node.js, TypeScript, GPT, Claude and Godot marks identify the corresponding tools; underlying trademark ownership remains with their respective owners. No third-party game texture pack is used. The scene is assembled from independent sprites rather than a flat illustration.
