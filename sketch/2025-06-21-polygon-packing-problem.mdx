# 装箱问题算法分类总表

| 主要分类         | 子分类       | 具体算法                       | 特点/应用场景          |
| ---------------- | ------------ | ------------------------------ | ---------------------- |
| **精确算法**     | 数学规划方法 | 分支定界法 (Branch and Bound)  | 理论最优解，小规模问题 |
|                  |              | 动态规划 (Dynamic Programming) | 伪多项式时间，中小规模 |
|                  |              | 整数线性规划 (ILP)             | 通用性强，求解器支持   |
|                  |              | 混合整数线性规划 (MILP)        | 处理复杂约束           |
|                  |              | 分支切割法 (Branch and Cut)    | 大规模精确求解         |
| **启发式算法**   | 简单启发式   | First Fit (FF)                 | 快速，在线算法         |
|                  |              | Best Fit (BF)                  | 空间利用率高           |
|                  |              | First Fit Decreasing (FFD)     | 预排序，性能稳定       |
|                  |              | Best Fit Decreasing (BFD)      | 综合性能良好           |
|                  |              | Next Fit (NF)                  | 内存友好               |
|                  | 贪心算法     | 基本贪心策略                   | 简单快速               |
|                  |              | 多阶段贪心                     | 考虑全局信息           |
|                  |              | 自适应贪心                     | 动态调整策略           |
|                  | 局部搜索     | 爬山算法 (Hill Climbing)       | 局部最优               |
|                  |              | 邻域搜索                       | 解空间探索             |
|                  |              | 变邻域搜索 (VNS)               | 跳出局部最优           |

|                  |              | 粒子群算法 (PSO)               | 收敛速度快             |

|                  |              | 大爆炸-大收缩                  | 动态搜索范围           |
|                  | 基于搜索     | 禁忌搜索 (TS)                  | 记忆机制               |
|                  |              | 散布搜索 (SS)                  | 多样性保持             |

|                  |              | 离线学习超启发式               | 预训练策略             |
|                  | 生成型       | 遗传编程生成                   | 自动生成启发式         |
|                  |              | 语法进化                       | 结构化启发式设计       |

## 算法选择指南

| 问题规模               | 时间要求 | 解质量要求 | 推荐算法类型      |
| ---------------------- | -------- | ---------- | ----------------- |
| 小规模 (\<100 项)      | 不限     | 最优解     | 精确算法          |
| 中等规模 (100-1000 项) | 适中     | 高质量解   | 启发式+元启发式   |
| 大规模 (>1000 项)      | 严格     | 可接受解   | 简单启发式        |
| 大规模 (>1000 项)      | 宽松     | 高质量解   | 元启发式+超启发式 |
| 实时应用               | 极严格   | 基本可行   | FFD/BFD           |
| 批量处理               | 宽松     | 最优化     | 混合算法          |
